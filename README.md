# Superannuation Retirement Planning Sensitivity Analysis

This project models retirement readiness for a hypothetical individual using financial planning assumptions, annuity calculations, Monte Carlo simulation, and sensitivity analysis.

## Business Problem

Retirement planning requires understanding whether current savings contributions, salary growth, inflation, and portfolio allocation are sufficient to meet future lifestyle needs. This project evaluates whether a projected retirement corpus can support expected expenses and tests how different assumptions affect the outcome.

## What This Project Demonstrates

- Retirement capital requirement modelling
- Present value and annuity-based financial planning logic
- Scenario analysis across base, best, and worst cases
- Monte Carlo-style simulation outputs
- Sensitivity analysis for contribution rates, salary growth, returns, inflation, and portfolio allocation
- Dashboard-style workbook presentation

## Tools Used

- Microsoft Excel
- Financial modelling
- Sensitivity analysis
- Scenario analysis
- Monte Carlo simulation
